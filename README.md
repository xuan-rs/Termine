# Termine

A fully CLI oriented Minecraft launcher

## Features

- Cross platform support `Win/Linux/MacOS`
- Multi threaded parallel download version
- Beautiful TUI

## How to download?

> In the early stages of development, the first version has not yet been released...

## Technical section

Completely written in Python, may integrate Rust in the future, and package using the "Nuitka" tool
